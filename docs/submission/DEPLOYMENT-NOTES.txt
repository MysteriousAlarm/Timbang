===============================================================================
 PROJECT TIMBANG - DEPLOYMENT NOTES
 Verified daily vegetable price board and produce marketplace for Nueva Vizcaya
 Version 0.1.1 (first build)  -  Repository: github.com/MysteriousAlarm/Timbang
===============================================================================

WHAT GETS DEPLOYED
  1. Firebase backend: Firestore rules + indexes, Storage rules, Cloud Functions
  2. Website + admin dashboard: Firebase Hosting (https://<project-id>.web.app)
  3. Android app: APK file installed on phones
  Firebase project used: timbang-nv  (region asia-southeast1, Blaze plan)

-------------------------------------------------------------------------------
A. REQUIREMENTS (one-time, on the PC that builds/deploys)
-------------------------------------------------------------------------------
  - Flutter 3.47 or newer          flutter --version
  - Android Studio + Android SDK    (for the APK), JDK 17 or 21
  - Node.js 22 or newer + npm      node -v
  - Firebase CLI                   npm install -g firebase-tools
  - Git                            git --version
  Windows PowerShell only: allow npm scripts once
      Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

-------------------------------------------------------------------------------
B. GET THE CODE AND INSTALL DEPENDENCIES
-------------------------------------------------------------------------------
  git clone https://github.com/MysteriousAlarm/Timbang.git
  cd Timbang
  npm install                       (scripts and rules tests)
  npm --prefix functions install    (Cloud Functions)
  cd app
  flutter pub get                   (app and website)
  cd ..

  Private files (NOT in the repository - keep them on a private drive):
    app/android/app/google-services.json     Android <-> Firebase config
    %USERPROFILE%\.android\debug.keystore     key that signs the APK
    %USERPROFILE%\keys\timbang-sa.json        service-account key (admin setup)
  Restore them in one step from the backup zip:
      powershell -ExecutionPolicy Bypass -File scripts\secrets-restore.ps1

-------------------------------------------------------------------------------
C. FIREBASE PROJECT (first time only)
-------------------------------------------------------------------------------
  1. Firebase console: create project, upgrade to Blaze (pay as you go).
  2. Authentication > Sign-in method > enable Phone.
     (Optional demo logins: Phone > "Phone numbers for testing", e.g.
      +63 917 000 0001 / code 123456. Remove before the real pilot.)
  3. Firestore Database: create in asia-southeast1. Storage: enable.
  4. Connect the app (only if the project changes):
       dart pub global activate flutterfire_cli
       cd app
       flutterfire configure --project=timbang-nv --platforms=android,web --android-package-name=ph.timbang.timbang --out=lib/core/firebase/firebase_options.dart
  5. Android signing fingerprints (phone login fails without them):
       keytool -list -v -keystore "%USERPROFILE%\.android\debug.keystore" -alias androiddebugkey -storepass android -keypass android
     Copy SHA1 and SHA256 to Firebase > Project settings > Android app
     ph.timbang.timbang > Add fingerprint.

-------------------------------------------------------------------------------
D. DEPLOY THE BACKEND (rules, indexes, functions)
-------------------------------------------------------------------------------
  firebase login
  firebase use timbang-nv
  firebase deploy --only firestore:rules,firestore:indexes,storage,functions
  (First functions deploy: 5-10 minutes; answer YES to enabling APIs.)

-------------------------------------------------------------------------------
E. BUILD AND DEPLOY THE WEBSITE + ADMIN DASHBOARD
-------------------------------------------------------------------------------
  cd app
  flutter build web --release -t lib/main_web.dart
  cd ..
  firebase deploy --only hosting
  Result: https://timbang-nv.web.app

-------------------------------------------------------------------------------
F. BUILD THE ANDROID APP (APK)
-------------------------------------------------------------------------------
  cd app
  flutter build apk --release -t lib/main_app.dart
  Output: app\build\app\outputs\flutter-apk\app-release.apk  (~60 MB)
  Smaller per-phone files:  flutter build apk --release --split-per-abi -t lib/main_app.dart
                            (give people app-arm64-v8a-release.apk)
  Install: copy the APK to the phone and open it (allow "Install unknown apps").
  Phones need Android 7.0 or newer.

-------------------------------------------------------------------------------
G. FIRST ADMINISTRATOR AND DATA
-------------------------------------------------------------------------------
  1. Open the app or website once and sign in with the admin's number.
  2. Grant the admin role (service-account key kept OUTSIDE the repository):
       PowerShell:
       $env:GOOGLE_APPLICATION_CREDENTIALS="$HOME\keys\timbang-sa.json"
       $env:GCLOUD_PROJECT="timbang-nv"
       npm run seed:admin -- +639XXXXXXXXX
     Sign out and in again. Profile now shows "Open the admin dashboard".
     (Typing role: admin into Firestore does nothing - roles are server-side claims.)
  3. Admin dashboard: import, in this order,
       Markets > Import Excel or CSV
       Commodities > Import Excel or CSV
       Prices > Import official prices
     The office's Excel file can be imported as it is (names, title rows and
     "one column per market" layouts are accepted). No rebuild is needed.
  4. When real data is in: Commodities/Markets > "Remove demo data".

-------------------------------------------------------------------------------
H. RUN LOCALLY WITHOUT A FIREBASE PROJECT (development / testing)
-------------------------------------------------------------------------------
  npm run emulators                         (Auth, Firestore, Functions, Storage)
  set FIRESTORE_EMULATOR_HOST=127.0.0.1:8080 && npm run seed:demo
  cd app
  flutter run -t lib/main_app.dart          (phone/emulator)
  flutter run -d chrome -t lib/main_web.dart (website + admin)
  Login codes appear in the Emulator UI: http://127.0.0.1:4000/auth

-------------------------------------------------------------------------------
J. UPDATING AFTER A CODE CHANGE
-------------------------------------------------------------------------------
  git pull origin main
  Backend changed?  firebase deploy --only functions   (or firestore:rules, storage)
  Website:          flutter build web --release -t lib/main_web.dart  then  firebase deploy --only hosting
  App:              bump "version:" in app/pubspec.yaml, then flutter build apk --release -t lib/main_app.dart

-------------------------------------------------------------------------------
K. TROUBLESHOOTING
-------------------------------------------------------------------------------
  "Expected to find project root"   -> run flutter commands inside the app folder
  npm.ps1 cannot be loaded          -> Set-ExecutionPolicy (section A)
  Gradle download fails (504)       -> download gradle-9.3.1-all.zip in a browser and put it in
                                       %USERPROFILE%\.gradle\wrapper\dists\gradle-9.3.1-all\<folder>\
  Phone login "not authorized"      -> add SHA1/SHA256 (section C5), wait 5 minutes
  "App not installed"               -> uninstall the old TIMBANG (different signing key)
  No admin dashboard                -> section G2, then sign out and in
  More: docs/BUILD.md and docs/APK_BUILD.md in the repository.
