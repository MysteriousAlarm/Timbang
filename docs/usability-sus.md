# Usability testing: System Usability Scale (SUS)

Run after a short task session (5 to 8 farmers, 3 to 5 buyers, 1 to 2 agriculture staff).

## Tasks
1. Mag-log in gamit ang iyong numero. (Log in with your number.)
2. Hanapin ang presyo ng kamatis sa iyong palengke. Gaano ito katagal na? (Find today's tomato price. How old is it?)
3. Ihambing ang presyo sa ibang palengke. (Compare with other markets.)
4. Farmers: Mag-post ng ani. / Buyers: Magtanong tungkol sa isang ani. (Post produce / ask about a listing.)
5. Mag-set ng alerto sa presyo. (Set a price alert.)
6. Basic phone: i-text ang PRESYO KAMATIS BAYOMBONG (Admin → SMS simulator for the demo).

## Questionnaire (1 = Lubos na hindi sang-ayon / Strongly disagree … 5 = Lubos na sang-ayon / Strongly agree)

1. Gusto kong gamitin ang TIMBANG nang madalas. (I would like to use TIMBANG frequently.)
2. Masyadong komplikado ang TIMBANG. (I found TIMBANG unnecessarily complex.)
3. Madaling gamitin ang TIMBANG. (I thought TIMBANG was easy to use.)
4. Kakailanganin ko ng tulong ng ibang tao para magamit ito. (I would need help from a technical person to use it.)
5. Magkakaugnay nang maayos ang mga bahagi nito. (The functions were well integrated.)
6. Masyadong maraming hindi pagkakatugma sa app. (There was too much inconsistency.)
7. Mabilis itong matututunan ng karamihan. (Most people would learn it very quickly.)
8. Mabigat o mahirap itong gamitin. (I found it very cumbersome to use.)
9. Kumpiyansa ako habang ginagamit ito. (I felt very confident using it.)
10. Marami akong kailangang matutunan bago ito magamit. (I needed to learn a lot before I could use it.)

## Scoring
For odd items: score − 1. For even items: 5 − score. Sum × 2.5 = SUS (0–100).
68 is average; aim for 70+ (good) in the pilot. Report the mean, median and comments per task.
